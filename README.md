# 🎓 Guru-Utsav 2026 | Teachers' Day Campus Celebration Portal

An all-in-one interactive web portal built for campus-wide Teachers' Day celebrations on **September 5th, 2026**.

## 🌟 Key Features

1. **⏳ Live Countdown Timer to Teachers' Day**:
   - Dynamic countdown clock ticking down Days, Hours, Minutes, Seconds to Sept 5, 2026 09:00 AM IST.
   - 1-click "Add to Google Calendar" and "Share Campus Invite" buttons.
   - Interactive celebratory confetti trigger.

2. **🎟️ ₹100 Campus Contribution & Pass Generator**:
   - ₹100 all-inclusive pass (Full Day Auditorium Entry, High-Tea & Refreshments coupon, Activity Eligibility, Digital Badge).
   - Dynamic UPI QR Code generator (`upi://pay`) and mobile 1-click UPI app launcher (GPay, PhonePe, Paytm, BHIM).
   - Attendee registration form capturing Name, Roll No., Department, Academic Year, WhatsApp No., and Payment UTR.
   - Instant **Downloadable & Printable Digital Pass Badge** with participant avatar initials, Ticket ID, and authentic verification QR code.

3. **🎭 Activity & Stage Performance Signup**:
   - Register solo or group performances in Singing/Band, Classical/Bollywood Dance, Drama/Comedy Skit, Shayari/Speech, Stand-up, or Anchoring.
   - Register for fun interactive games (Teacher-Student Quiz, Musical Chairs, Pictionary).
   - Live registered acts lineup with slot counters.

4. **💌 Wall of Gratitude (Teacher Dedication Wall)**:
   - Students & alumni can post appreciation notes with virtual gifts (💐 Bouquet, ⭐ Mentor Star, 🍫 Chocolates, 🏆 Golden Trophy, ☕ Coffee, 🌺 Lotus).
   - Card theme customization (Amber, Pink, Purple, Emerald).
   - Real-time search by teacher or student name and category filtering.
   - Interactive "Heart / Like" reaction system with micro-confetti.

5. **🏆 Faculty Spotlight & Campus Awards Poll**:
   - Faculty showcase cards with catchphrases, subjects, and quick "Send Wish" links.
   - Live Student-Choice Awards Voting poll with animated percentage bars.

6. **📅 Event Day Schedule & Itinerary**:
   - Detailed timeline covering the Red Carpet welcome, Lamp lighting, Cultural Acts Phase 1 & 2, Banquet Lunch, Fun Olympiad, and Award presentations.

7. **🛡️ Organizer / Admin Dashboard**:
   - Real-time KPI summary (Total ₹ Funds raised, Passes issued, Acts registered, Dedications).
   - Searchable table for ₹100 Pass Registrations with payment verification toggle.
   - Performance acts scheduling roster.
   - 1-click **Export to CSV** for Excel and registration desks.
   - Reset Demo Data option.

## 🚀 How to Run the Website Locally

### Option 1: Direct Browser Launch
Simply double click `index.html` in your file explorer or right click -> **Open with Chrome / Edge / Firefox**.

### Option 2: Using the Python Dev Server
Open your terminal in this directory and run:
```bash
python server.py
```
This will start a local server on `http://localhost:8080` and open your browser automatically.
